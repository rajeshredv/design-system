Toggle

A switch that turns a single setting on or off and takes effect immediately, like enabling notifications. For choices that apply only after the user presses Save, use a checkbox instead.

Figma: Toggle Node 2050:3135 4 variants 32 × 18px Light & dark

Variants

The Figma property States has four values. In code they come from the native checkbox's :checked and :disabled states, so there are no modifier classes to manage.

Playground

Click the switch, or tab to it and press Space.

State: Off

Anatomy & sizing

  1. Track: 32 × 18px, radius --radius-pill (28px, fully rounded)
  2. Knob: 16 × 16px, inset 1px from the track edge
  3. Travel: the knob moves from x = 1px (Off) to x = 15px (On), a 14px slide animated over 150ms
  4. Label (optional, code only): 8px gap (--space-l), 14px text

Usage

HTML + CSS

<link rel="stylesheet" href="tokens.css">
<link rel="stylesheet" href="toggle.css">

<!-- With a visible label (preferred) -->
<label>
  <input type="checkbox" role="switch" class="toggle">
  Email notifications
</label>

<!-- Without a visible label -->
<input type="checkbox" role="switch" class="toggle" aria-label="Email notifications">

<!-- On / disabled -->
<input type="checkbox" role="switch" class="toggle" checked>
<input type="checkbox" role="switch" class="toggle" disabled>

Vue

<script setup>
import { ref } from "vue";
import Toggle from "./design-system/components/Toggle.vue";
const notify = ref(true);
</script>

<template>
  <Toggle v-model="notify">Email notifications</Toggle>
  <Toggle v-model="notify" label="Email notifications" />  <!-- no visible label -->
  <Toggle :model-value="true" disabled>Sync</Toggle>
</template>

Light and dark mode

The toggle follows the OS setting. To force a theme, set data-theme="light" or data-theme="dark" on <html> or on any container.

Accessibility

  • Use <input type="checkbox" role="switch">. Screen readers announce it as a switch that is "on" or "off", and Space toggles it.
  • Always give it a name: a wrapping <label>, or aria-label when there's no visible text.
  • Focus shows a 2px --color-button-1000 outline with a 2px offset. Figma has no focus state, so this was added in code.
  • Contrast: the Off track is faint against the page in both themes. It's about 1.7:1 on white in light mode and 1.5:1 on #2B2B2B in dark mode, below the WCAG 3:1 minimum for controls. In dark mode the knob (#2B2B2B) is also only about 1.5:1 against the Off track. The On state passes in both themes. Pair the toggle with a visible label so its purpose doesn't rely on seeing the track.
  • The knob slide is disabled when the user has prefers-reduced-motion set.

Guidelines

✓ Do

  • Use it for settings that take effect right away
  • Put the label next to the switch, describing what "on" means
  • Keep labels the same in both states: "Email notifications", not "On" / "Off"

✗ Don't

  • Use it inside a form that needs a Save button. Use a checkbox
  • Use it to pick between two different options, like "List" / "Grid"
  • Resize or recolor it with hex values. Use the tokens
