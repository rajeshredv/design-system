Dropdowns & menus

A compact trigger that opens a floating list: an action menu (Forward, Copy, Delete), a single-choice filter with a check-mark, or a searchable picker for long lists like time zones. The page also covers the segmented control, a pill-shaped switcher for choosing one of two to four options.

Dropdown items

Figma: Dropdown items - Small 3167:2219 · 5 variants Figma: Dropdown items - Medium 3167:2251 · 3 variants .menu-item · MenuItem.vue

A row is a leading icon (optional), a label, and an optional trailing badge or check-mark. These are separate elements in code, not modifier classes. The check-mark appears when the row has aria-checked="true" (menus) or aria-selected="true" (listboxes). Rows are Small by default and become Medium inside .menu--medium or with .menu-item--medium.

Segmented control

Figma: Text & Icon Node 3315:2664 12 variants 40px tall segmented.css · SegmentedControl.vue

The Figma set is named Text & Icon and its twelve variants have frame names. They form a segmented control: a pill track holding two segments, with the selected one raised on a white pill. The twelve variants are three layouts × four states. In code it's a group of native radio buttons, so selection comes from :checked and disabled from :disabled. There are no state classes. The .is-hover class exists only so these docs can show the hover state.

The components are Dropdown.vue, DropdownMenu.vue, MenuItem.vue and SegmentedControl.vue. They have no <style> blocks, so load the CSS files above globally.

Light and dark mode

Everything follows the OS setting. To force a theme, set data-theme="light" or data-theme="dark" on <html> or on any container.

Accessibility

  • Trigger: a native <button> with aria-haspopup="menu" (or "listbox" for the search picker), aria-expanded and aria-controls. Enter, Space and ↓ open the menu and focus the first row (or the checked one). ↑ opens it and focuses the last row.
  • Action menus use role="menu" with role="menuitem" rows. Single-choice menus use role="menuitemradio" with aria-checked, and the check-mark is drawn from that attribute, so the visuals and semantics can't drift apart. Rows get roving focus (tabindex="-1"): ↑ ↓ wrap around, Home and End jump, a letter jumps to the next row that starts with it, Enter and Space activate.
  • Search selection is a combobox. Focus stays in the role="combobox" input, the list is role="listbox" with role="option" rows and aria-selected, and ↑ ↓ move aria-activedescendant. Typing filters the list, and Enter picks the highlighted option.
  • Escape closes the menu and returns focus to the trigger. Tab and clicking outside close it without moving focus back.
  • Disabled rows use aria-disabled="true". They stay focusable so screen reader users can find them, but they can't be activated. Figma has no disabled row, so this state was added in code using Disabled.
  • Focus on the trigger and on rows shows a 2px --color-button-1000 ring (inset on rows), since Figma has no focus state. Keyboard focus on a row also shows the hover fill.
  • Icons are decorative (aria-hidden). The badge number is read as part of the row name, for example "Unread 2". If that's ambiguous, add visually hidden text such as "2 unread".
  • Segmented control: native radios in a role="radiogroup" with a label, so arrow keys move the selection. For Icon only, give each radio an aria-label.
  • Contrast: the disabled label (#C4C4C4 on white) is well below 4.5:1, which WCAG allows for disabled controls. In dark mode the Surface #E5-a50 track has the same value as in light mode, so it shows as a light grey band around the #2B2B2B selected pill.
  • Background and focus-ring transitions are turned off when the user has prefers-reduced-motion set.
