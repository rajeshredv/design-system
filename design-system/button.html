Button — Primary / Medium

The main call to action in a view, like Reply, Save, or Send. Use only one primary button per area, and put it on the highest-priority action.

Figma: Buttons-Primary/Medium Node 2145:2682 5 variants Height 36px

Variants

The Figma property Property 1 has five values. In code, each value maps to a native state or ARIA attribute, not a modifier class.

Playground

Hover, press, and tab to the live button to see the real interaction states.

Anatomy & spacing

  1. Container: auto-layout, horizontal, centered. min-width: 90px, radius: 4px
  2. Padding (pink): vertical --space-l 8px · horizontal --space-xl 12px
  3. Label: BTN Medium text style, 20px line-height. fixed height --control-height-md = 36px
  4. Loader (Loading only): 24px icon. The fixed height keeps it at 36px, the same as the label states

Usage

<link rel="stylesheet" href="tokens.css">
<link rel="stylesheet" href="button.css">

<!-- Default -->
<button class="btn-primary-md" type="button">Reply</button>

<!-- Activated (toggle) -->
<button class="btn-primary-md" type="button" aria-pressed="true">Reply</button>

<!-- Loading -->
<button class="btn-primary-md" type="button" aria-busy="true" aria-label="Reply, loading">
  <img class="btn-primary-md__spinner" src="assets/loader.svg" width="24" height="24" alt="">
</button>

<!-- Disabled -->
<button class="btn-primary-md" type="button" disabled>Reply</button>

Theming a single instance

The component reads three local variables. Override them on one element instead of editing the global tokens.

.my-context .btn-primary-md {
  --btn-bg: var(--color-button-1000);
  --btn-fg: var(--color-bg-1);
  --btn-border: transparent;
}

Accessibility

  • Use a native <button>. It gives you keyboard support (Enter/Space) and focus for free.
  • Focus shows a 2px --color-button-1000 outline with a 2px offset. Don't remove it.
  • Contrast: white on #0087ED is about 3.7:1, which only passes WCAG AA for large text. At 16px Medium it counts as normal text, so it falls short of 4.5:1. --color-button-1000 (#0076CE) passes at about 4.7:1.
  • Loading: set aria-busy="true" and keep the label as an aria-label, so screen readers still announce the action.
  • Activated as a toggle: use aria-pressed so assistive tech announces the on/off state.
  • Disabled buttons can't be focused. If users need to learn why an action is unavailable, use aria-disabled="true" with an explanation instead.

Guidelines

✓ Do

  • Use one primary button per section, for the main action
  • Write labels as short verbs: “Reply”, “Save”, “Send”
  • Keep the 90px minimum width so buttons line up

✗ Don't

  • Stack several primary buttons next to each other
  • Wrap labels onto two lines. The label is nowrap
  • Use hex values directly. Always reference the tokens
