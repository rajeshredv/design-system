Button flex

The action row used at the bottom of dialogs. Medium rows are right-aligned with a 24px gap; large rows are centered. It only arranges buttons from button.css. It has no colors of its own.

Color

None. Button colors come from button.css: Secondary (BG/2 / Text/T3), Primary (Button/800 / BG/1), Negative (Negative/800 / BG/1), Negative secondary (Negative/100 / Negative/800), Link (Button/800).

    </div>
  </form>

<!-- Destructive confirmation -->
<dialog class="confirm" id="confirm-delete" role="alertdialog"
        aria-labelledby="cd-title" aria-describedby="cd-desc">
  <div class="confirm__text">
    <h2 class="confirm__title" id="cd-title">Delete this message?</h2>
    <p class="confirm__description" id="cd-desc">This change cannot be undone.</p>
  </div>
  <form method="dialog" class="button-flex">
    <button class="btn btn--secondary btn--medium" value="cancel" autofocus>Cancel</button>
    <button class="btn btn--negative btn--medium" value="delete">Delete</button>
  </form>
</dialog>

Accessibility

  • Use a native <dialog> opened with showModal(). The browser traps focus inside it, makes the rest of the page inert, closes it on Escape, and returns focus to the element that opened it.
  • Name every dialog with aria-labelledby pointing at its title, and point aria-describedby at the description when there is one.
  • Destructive confirmations use role="alertdialog" and put autofocus on Cancel, so pressing Enter straight away doesn't delete anything. ConfirmDialog does both when tone="danger".
  • When an acknowledgement checkbox is shown, the confirm button stays disabled until it's ticked. This is added in code; Figma shows the button enabled.
  • Header icon buttons have no visible text, so each needs an aria-label ("Close", "Back", "More"). The icon itself is aria-hidden.
  • Focus shows a 2px --color-button-1000 outline with a 2px offset on the icon buttons and checkbox. Figma has no focus state.
  • Contrast: Text/Secondary on BG/1 is 5.7:1 in light and 6.8:1 in dark mode. The danger title (Negative/800 #EB5757 on white) is 3.5:1, which passes only because it is 20px bold (large text). The checkbox border (Text/T1) is 3.5:1 on white and 3.8:1 on #2B2B2B, above the 3:1 minimum for controls.
  • The open animation is turned off when prefers-reduced-motion is set.

Guidelines

✓ Do

  • Write the title as the question or the outcome: "Delete channel", not "Warning"
  • Label buttons with the action: "Delete", "Use here", "Sign in"
  • Use the negative buttons and the warning icon for actions that can't be undone

✗ Don't

  • Stack dialogs on top of each other
  • Use a confirmation for actions that are easy to undo. Show an undo toast instead
  • Put more than three buttons in a Button flex
