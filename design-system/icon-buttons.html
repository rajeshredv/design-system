Icon buttons

Buttons that show only an icon, for compact or frequent actions like reacting, forwarding, deleting or closing. They share one class, .icon-btn, with a style modifier and a size modifier. Every icon button needs an aria-label.

Icon button: variants

Each Figma set maps to a style and a size. The Figma property States maps to :hover, :active / aria-pressed="true" and :disabled. The Hover and Active columns below are forced with .is-hover and .icon-btn--pressed so the states can be seen side by side.

  <span class="icon" style="--icon:url(assets/icons/emoji-smiley.svg)" aria-hidden="true"></span>
</button>

<button type="button" class="icon-btn icon-btn--hard-fill icon-btn--small" aria-label="Call">
  <span class="icon" style="--icon:url(assets/icons/call.svg)" aria-hidden="true"></span>

<!-- Toggle button: aria-pressed switches the Active frame on and off -->
<button type="button" class="icon-btn icon-btn--soft-fill icon-btn--large" aria-label="Mark as done" aria-pressed="false">…</button>

<!-- Badge: put the count in the accessible name too -->
<button type="button" class="icon-btn icon-btn--transparent icon-btn--large" aria-label="Reactions, 2 new">
  <span class="icon" style="--icon:url(assets/icons/emoji-smiley.svg)" aria-hidden="true"></span>
  <span class="icon-btn__badge" aria-hidden="true">2</span>
</button>

  <button type="button" class="icon-btn icon-btn--transparent icon-btn--large" aria-label="Sort">…</button>
  <button type="button" class="icon-btn icon-btn--transparent icon-btn--large" aria-label="More options">…</button>

Vue

<script setup>
import { ref } from "vue";
import IconButton from "./design-system/components/IconButton.vue";
import IconButtonCluster from "./design-system/components/IconButtonCluster.vue";
const done = ref(false);
</script>

<template>
  <IconButton label="Add reaction" icon="/assets/icons/emoji-smiley.svg" />
  <IconButton label="Call" icon="/assets/icons/call.svg" variant="hard-fill" size="small" />
  <IconButton label="Delete" icon="/assets/icons/delete.svg" variant="negative" size="small" />
  <IconButton label="Remove attachment" icon="/assets/icons/close.svg" variant="micro" />
  <IconButton label="Mark as done" icon="/assets/icons/tick.svg" variant="soft-fill"
              :pressed="done" @click="done = !done" />
  <IconButton label="Reactions" icon="/assets/icons/emoji-smiley.svg" :badge="2" badge-label="2 new" />

  <IconButtonCluster label="Panel actions">
    <IconButton label="Sort" icon="/assets/icons/sort-ascending.svg" />
    <IconButton label="More options" icon="/assets/icons/more-meatballs.svg" />
    <IconButton label="Close" icon="/assets/icons/close-line2.svg" />
  </IconButtonCluster>
</template>

Props: label (required), icon, variant (default transparent), size (default large), pressed, disabled, badge (number/string for a count, true for the dot), badge-label. The default slot replaces the icon, e.g. for .icon-btn__add.

Light and dark mode

Icon buttons follow the OS setting. To force a theme, set data-theme="light" or data-theme="dark" on <html> or on any container. Icons are CSS masks filled with currentColor, so they switch with the button.

Accessibility

  • Always use a native <button type="button"> and give it an aria-label that names the action (“Delete message”, not “Trash”). The Vue label prop is required for this reason. Icons are aria-hidden.
  • Only add aria-pressed to buttons that toggle something on and off; it makes screen readers announce “pressed” / “not pressed”. Momentary press feedback comes from :active.
  • The badge is aria-hidden; put the count or “new” in the accessible name instead (the Vue component does this for you).
  • Focus shows a 2px --color-button-1000 outline with a 2px offset. Figma has no focus state (3628:2793's “Focus” frame is the same outlined frame the other sets call Active), so the ring was added in code.
  • Icon-Large-Secondary 3016:6371's Disabled frame looks exactly like Default. It's kept as designed, so a disabled Secondary button is only distinguishable by the not-allowed cursor and by assistive tech. Prefer hiding the action, or ask design for a disabled treatment.
  • Target size: Micro (20px) and xsmall (24px) are below the 24px WCAG 2.2 minimum (Micro) or at it (xsmall). Leave spacing around them so neighbouring targets don't overlap.
  • Contrast: Micro's icon uses BG/1, which is #2B2B2B in dark mode, on a 40% black scrim, so it is very faint in dark mode. Kept as designed; place Micro buttons only on light imagery, or ask design for a dark-mode icon color.
  • Color transitions are turned off when prefers-reduced-motion is set.

Guidelines

✓ Do

  • Use icons whose meaning is widely understood (close, delete, more)
  • Use Hard-fill for one primary action per area; Transparent everywhere else
  • Use Negative only for destructive actions, and confirm them

✗ Don't

  • Ship an icon button without an aria-label
  • Mix sizes inside one cluster
  • Recolor icons with hex values. Override --icon-btn-fg / --icon-btn-bg with tokens
