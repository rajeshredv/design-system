App patterns

Product pieces of the Arattai chat app: the banner at the top of the left-hand chat list, the strip under the chat header, the centered message of a full-window notice and the Create group dialog. They're built from the shared tokens and buttons, and their product content (names, photos, copy) comes in through props and slots.

Accessibility

  • The banner is a <section> named by its title (aria-labelledby), so screen reader users can find it as a region.
  • The action is a real <button>. Use a label that makes sense on its own ("Turn on", "Refresh").
  • The close button has aria-label="Dismiss". When it removes the banner, move focus to the next element in the list so focus isn't lost.
  • The icons are decorative (aria-hidden). The title carries the meaning.
  • Contrast: the dark-mode sub text is #FFFFFF on #3D3D3D (high). In light mode, #747474 on #F1F4F7 is about 4.3:1, just below the 4.5:1 AA minimum for 14px text.

Accessibility

  • Each strip is a named region (role="region" + aria-label), so screen reader users can jump to it.
  • The pinned message row is one <button> that jumps to the message. The photo icon has role="img" and aria-label="Photo", so it reads as "Abishek: Photo This is the spot…".
  • Avatars are decorative (alt=""). The label already says how many requests there are.
  • The close icon, which is a plain icon in Figma, is a 24px <button> with aria-label="Dismiss". It's smaller than the 44px touch target guideline, so give it more padding on touch layouts.
  • All buttons show the 2px --color-button-1000 focus ring.

Accessibility

  • Use a native <dialog> with showModal(). That gives you a focus trap, Escape to close and an inert page behind it. It's named by its title through aria-labelledby.
  • Each field is a real <input> or <textarea> wrapped in a <label>, so the floating text is its accessible name. "Group name" is required. The red asterisk is aria-hidden because the required state is announced.
  • Fields show a 2px --color-button-1000 focus ring on the box. It's added in code because the Figma "Composed" (filled) and "Focus" borders are both Button/800, so the border alone doesn't show focus.
  • The photo is a button named "Change group icon" and described by the "Set Group Icon (optional)" hint.
  • The close and emoji buttons are icon-only and have aria-labels. Group settings is a button whose visible text is its name.
  • Transitions are turned off when prefers-reduced-motion is set.
